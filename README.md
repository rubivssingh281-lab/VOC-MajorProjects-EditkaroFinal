# Editkaro — Motion & Film Studio

A single-page, animation-heavy portfolio website for **DRIFT**, a fictional motion & film studio brand ("Editkaro"). Built as a major project showcasing scroll-driven storytelling, video reels, and modern front-end motion design.

**Live Site:** [rubivssingh281-lab.github.io/VOC-MajorProjects-EditkaroFinal](https://rubivssingh281-lab.github.io/VOC-MajorProjects-EditkaroFinal/)

---

## ✨ Overview

Editkaro is a stylized agency/portfolio landing page for a motion design and film studio. The site tells the studio's story through scroll-based sections, embedded video reels, animated statistics, client testimonials, and a project showcase — mimicking the feel of a real high-end creative studio website (Awwwards / FWA style).

## 📄 Sections

- **Hero / Landing** — Animated intro ("Drift In") with navigation to Story, Work, Categories, Reel, Studio, and Contact
- **Studio Intro** — Brand statement and founding details (Est. 2018, Based in Lisbon / Remote)
- **Reel (2016–2026)** — Three core pillars: *Craft*, *Story*, and *Systems*, each paired with a looping video
- **How We Work** — Three-phase process: *Listen*, *Choreograph*, *Ship*
- **The Studio** — Philosophy, people, and practice of the team (9 people, 2 cities)
- **Selected Work** — Six featured projects (Northline, Auric, Verdant, Halcyon, Oskar & Fine, Ferro) with a showreel
- **Recognition** — Awards and honors (Awwwards, FWA, CSSDA, D&AD, SXSW, etc.)
- **Categories** — Browse work by category (AI, Architecture & Design, Beauty, Characters, Luxury, Set Design, Typography)
- **Client Words** — Testimonial carousel from past clients
- **Behind the Reel** — Behind-the-scenes photos/videos from shoots
- **Stats** — Years in motion, films shipped, global brands, specialists
- **Contact** — Enquiry form and social links (Instagram, Vimeo, LinkedIn)

## 🛠️ Built With

- HTML5
- CSS3 (custom animations, scroll effects)
- JavaScript
- Embedded video assets (MP4 reels)
- Hosted via **GitHub Pages**

## 🚀 Getting Started

To run this project locally:

```bash
git clone https://github.com/rubivssingh281-lab/VOC-MajorProjects-EditkaroFinal.git
cd VOC-MajorProjects-EditkaroFinal
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```

## 🌐 Deployment

This project is deployed using **GitHub Pages** from this repository. Any changes pushed to the default branch (configured for Pages) will automatically reflect on the live site.
